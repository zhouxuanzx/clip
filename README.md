# Clip — 剪贴板管理器（桌面 + 安卓）

电脑端自动记录剪贴板历史，支持自定义分类、待办、收藏；
手机端通过局域网与电脑同步，内容端到端加密。

## 在电脑上跑起来

只需要 Node.js（>= 22），**不需要装 Visual Studio Build Tools**——
better-sqlite3 v13、koffi、robotjs 都自带预编译二进制。

```bash
cd desktop
npm install
npm run dev
```

打包（输出到 `desktop/release/`，portable exe + zip，不签名）：

```bash
cd desktop
npm run build:win
```

## 在手机上跑起来

用 Android Studio 打开 `android/` 目录，直接 Run 即可（Gradle 依赖会自动下载）。
仓库里没有 `gradle-wrapper.jar`（二进制不入库），Android Studio 首次打开会自动补上；
命令行构建的话先执行一次 `gradle wrapper`。

## 配对与同步

1. 电脑端左下角「手机」→ 开启局域网服务 → 「配对新手机」显示二维码。
2. 手机端设置页 →「扫码配对」，扫上一步的二维码。两台设备要在同一个局域网。
3. 之后手机端点「连接」就能重连，不用再扫码。电脑换了 IP 就重新扫一次。

每个分类可以单独设同步策略：

| 策略 | 行为 |
|---|---|
| 不同步 | 完全不参与同步 |
| 手动推送 | 只在你点「推送」时把选中的条目发过去 |
| 自动同步 | 两端保持一致，增删改都会传播 |

剪贴板分类默认是「手动推送」——它每天进上百条，全自动同步既费流量也没意义。

## 交互

| 操作 | 效果 |
|---|---|
| 全局热键（默认 ``Alt+` ``） | 唤起/收起窗口 |
| 单击条目 | 复制回系统剪贴板 |
| 点击「粘贴」按钮 | 复制到剪贴板并收起窗口；开启「自动粘贴」时粘贴回原窗口 |
| 双击条目 | 剪贴板条目无动作；列表/待办条目进入编辑 |
| Ctrl + 单击 | 多选 |
| 双击左侧分类 | 改名 |
| Esc | 收起窗口 |

> 早期版本里双击条目会直接粘贴并关窗，现已取消，改为显式的「粘贴」按钮。

手机端不自动抓剪贴板：安卓 10 起后台读剪贴板被系统禁掉，前台读也会弹
「XX 已粘贴」的提示。手机侧的入口是**系统分享菜单**和界面里的「+」。

## 设计要点

- **左侧菜单是数据不是代码**：剪贴板/收藏/待办只是三条预置记录，新增分类就是插一行。
- **"加入收藏"是复制新条目而非改归属**：剪贴板分类按上限滚动淘汰，改归属会让淘汰逻辑和收藏语义打架。
- **淘汰用物理删除、用户删除用墓碑**：这样电脑上清理旧记录不会把同步到手机的那条也删掉。
- **图片按内容 hash 命名**：天然去重，多个条目共享一个文件，删除前检查引用。
- **手机永远是客户端**：手机 IP 变动频繁、还会被系统随时冻结，让它主动连电脑更靠谱。
- **冲突用 LWW**：比 `updatedAt`，相同则比 id 字符串序——两端各自独立计算也能得到同一结论，
  不会出现"我覆盖你、你覆盖我"的来回震荡。
- **`lastSyncAt` 只由自己的 push 被 ack 时推进**：它表示"本机变更已发送到哪个时刻"，
  用对端的时间戳去推进会因时钟偏差漏发本机的改动。

## 安全模型

- 二维码里是一次性配对码（32 字节随机数），用完即失效，配对窗口 3 分钟过期。
- 配对时两端各出一个 16 字节随机数，用 HKDF-SHA256 从配对码派生长期会话密钥各存一份。
- 每次连接再从会话密钥派生本次连接专用的传输密钥，之后所有消息都是 AES-256-GCM 加密帧。
- 解密成功本身就是身份证明——密钥不对时 GCM 校验必然失败，不需要额外的挑战应答。
- 帧格式 `[1B 版本][12B IV][密文][16B tag]`，IV = 4 字节连接前缀 + 8 字节递增计数器，
  接收端校验前缀一致且计数器严格递增，拒绝重放。

`desktop/shared/sync.ts` 与 `android/.../sync/Protocol.kt` 是同一份契约的两个副本，
改一边必须改另一边，并一起升 `PROTOCOL_VERSION`。
